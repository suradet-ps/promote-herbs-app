This repository contains a single, self-contained HTML file that serves as a promotional landing page for the main [**Thai Herbal Formulary App**](https://github.com/pharmacist-sabot/herbs-app).

The purpose of this page is to provide a quick, attractive overview of the application's features and guide users to access it, either through a direct link or a QR code. It is designed to be easily shared or hosted as a simple entry point for new users.

## ✨ Key Features of this Landing Page

-   **Single File, Zero Dependencies:** The entire page is contained within one `promotion.html` file, making it extremely portable and easy to deploy.
-   **Clear Call-to-Action:** Features a prominent button and a QR code section to direct users to the live application.
-   **Modern & Clean Design:** The styling is inspired by the main application's theme, providing a consistent user experience.
-   **Responsive Layout:** The page is fully responsive and looks great on both desktop and mobile devices.
-   **Informative Content:** Clearly outlines the key benefits and features of the main herbs application.

## 🚀 How to Use

### Local Viewing
Simply clone this repository and open the `promotion.html` file in your web browser.

```sh
git clone https://github.com/pharmacist-sabot/promote-herbs-app.git
cd promote-herbs-app
# Open promotion.html in your browser
```

### Deployment
This file is ready to be deployed on any static web hosting service, such as GitHub Pages, Netlify, or Vercel.

### Important Note
The page includes a placeholder for a QR code (`qr-code.png`). To make it functional, you should:
1.  Generate a QR code that points to the live URL of the main application (e.g., `https://herbs-app.rxdevman.com/`).
2.  Name the generated image file `qr-code.png`.
3.  Place it in the root directory of this repository.
